# P1 — Bootstrap Standalone `admin/` Next.js App

## Objective

Create the standalone application shell without moving Admin behavior yet.

## Create

```text
admin/
├── src/app/layout.tsx
├── src/app/globals.css
├── src/app/page.tsx
├── public/
├── package.json
├── tsconfig.json
├── next.config.ts
├── postcss.config.mjs
└── .env.example
```

Include `next-env.d.ts` if required/generated by Next.

## Version policy

Use versions compatible with the root application's current:

- Next.js;
- React;
- React DOM;
- TypeScript;
- Tailwind/PostCSS.

Do not upgrade packages during migration.

## `package.json`

Start minimal.

Add packages only when P0 import inventory proves Admin needs them.

Do not copy unrelated user-app dependencies such as chatbot/AI packages unless Admin actually imports them.

## `tsconfig.json`

Admin alias must be local:

```json
"paths": {
  "@/*": ["./src/*"]
}
```

Exclude nothing outside Admin unless required.

Do not include repository-wide `**/*.ts` patterns that accidentally typecheck root user app/backend.

## Global CSS

Copy root `src/app/globals.css` into Admin as compatibility baseline.

Do not edit visual tokens in this phase except paths/imports required to compile.

## Root layout

Create Admin-specific root layout.

Preserve fonts needed for visual parity.

Include only:
- global CSS;
- toaster if required;
- minimal Admin providers required after P3.

Do NOT add:
- BetaTesterModal;
- ChatbotFab;
- UMKM/Creator app chrome.

## Root page

Target final behavior:

```ts
redirect("/dashboard")
```

It can initially point to a placeholder until P2 routes exist.

## `next.config.ts`

Start from the current app requirements but keep only Admin-relevant config.

Preserve image host patterns used by Admin content.

Do not automatically bind the Admin app to the same Sentry project unless current operational requirements explicitly require it.

If Admin Sentry setup is omitted, record it as deployment follow-up rather than silently pretending parity.

## Verification

From `admin/`:

```bash
npm install
npm run typecheck
npm run build
```

A placeholder shell should build before code migration.

## Exit criteria

A standalone empty Admin Next app exists and compiles independently.
