# UI Components

This directory contains reusable, "dumb" UI components that are purely presentational.
Examples: `Button`, `Input`, `Card`, `Modal`, etc.
These components should not contain business logic or data fetching.

## Icon Usage Guidelines
- Use **Lucide React** for all new components and shadcn components.
- Use **Phosphor Icons** for legacy components (avoid bulk replacing to maintain compatibility).
- Ensure all icon-only buttons have an `aria-label` attribute for accessibility.
